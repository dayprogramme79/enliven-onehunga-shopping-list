How it works

  1. Upload your menu picture or file and press Read source.
  2. Check the extracted text, then press Fill daily menu form from text.
  3. Check the location, dates, Morning Tea, Lunch and Dessert columns. Correct anything OCR missed.
  4. Press Create / update shopping list from menu. Repeated items are grouped by meal category, with the dates they are needed.
  5. Enter the actual number to buy, save, and export the Excel file for Google Sheets.

This browser app does not directly write to Google Drive. Export the workbook, then use Google Sheets → File → Import → Upload. Saved changes stay in this browser on this device; export a backup when needed.
